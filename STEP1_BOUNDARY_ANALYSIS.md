**ファイル:** `phi_os/human_gate.py:138-152`

```python
def submit(payload: dict, conn=None) -> dict:
    """新規Human Gateリクエストを生成し、PENDING状態のeventを記録する。"""
    request_id = payload.get("request_id") or _next_event_id()
    existing = get_state(request_id, conn=conn)
    if existing is not None:
        raise HumanGateError(f"request_id already exists with state={existing}")
    return _record_transition(conn, "submit", request_id, payload, previous_state=None)
```

### HAB.approve(request_id, payload)
**ファイル:** `phi_os/human_gate.py:176-218`

```python
def approve(request_id: str, payload: dict | None = None, conn=None) -> dict:
    """
    Human Gate approval with HG-AS-01 Authorization State issuance.
    """
    event = _transition("approve", request_id, payload, conn=conn)
    if HG_AS_01_AVAILABLE and event.get("next_state") == "APPROVED":
        # authorization_state を自動生成
        if is_valid:
            success, auth_error, authorization_id = issue_authorization_state(request_id, conn=conn)
            if success:
                event["authorization_id"] = authorization_id
                event["decision_id"] = decision_id  # STEP 2で追加
    return event
```

## D. HABBridge の責務

**入力:**
- AI からの request（title, description, tags, model, source等）

**出力:**
- decision_id
- authorization_id
- execution_id（T2 Runtime 実行後）

**責務:**
1. AI request を HAB payload に正規化
2. HAB.submit() を呼ぶ → request_id取得
3. HAB.approve() を呼ぶ → authorization_id取得
4. authorization_state から decision_id を取得
5. JARVIS.receive_decision_from_hab() を呼ぶ → execution_id取得

**NOT 責務:**
- ✗ AI 固有の API処理
- ✗ Authentication
- ✗ 新しい Authorization ロジック

## E. 最小 Bridge 実装の方針

### ファイル: gateway/hab_bridge.py（新規）

```python
class HABBridge:
    """
    AI Adapter から HAB Core へのシンプルな Bridge.
    AI固有処理を持たず、既存HAB Coreへ薄く接続する.
    """
    
    def submit_from_ai(self, ai_identity: str, context: dict) -> str:
        """
        AI からのリクエストを HAB.submit() へ渡す.
        戻り値: decision_id（後で JARVIS 経由で T2 へ）
        """
        # AI identityを actor に正規化
        payload = {
            "decision_id": context.get("decision_id") or self._gen_decision_id(ai_identity),
            "actor": ai_identity,
            "scope": context.get("scope", ["default"]),
            "authority_role": context.get("authority_role", "AI_AUTHORITY"),
            "note": context.get("note", ""),
        }
        event = submit(payload)
        return payload["decision_id"]
    
    def approve_decision(self, request_id: str, decision_id: str) -> str:
        """
        HAB approval を実行.
        戻り値: authorization_id
        """
        payload = {
            "decision_id": decision_id,
            "actor": "HUMAN_AUTHORITY",  # または request payload から
            "scope": [...],  # authorization_state から取得
            "authority_role": "HAB_APPROVER",
        }
        event = approve(request_id, payload)
        return event.get("authorization_id")
    
    def route_to_jarvis(self, decision_id: str) -> str:
        """
        JARVIS へ routing.
        戻り値: execution_id
        """
        jarvis = JarvisEngine()
        result = jarvis.receive_decision_from_hab(decision_id)
        return result.get("execution_id")
```

## F. 対象 Adapter の選択

### 最初に接続する Adapter: adapter_gpt.py

理由:
- 最も単純な Function Call インターフェース
- 既存の handle_function_call() を再利用可能
- 他の Adapter への拡張が容易

### 接続変更:
```python
# 変更前
def handle_function_call(title, description, tags, ...):
    payload = {
        "title": title,
        "description": description,
        "tags": tags,
        ...
    }
    requests.post(f"{GATEWAY_BASE}/api/v1/event", json=payload, ...)

# 変更後
from gateway.hab_bridge import HABBridge

def handle_function_call(title, description, tags, ...):
    bridge = HABBridge()
    
    # HAB へ submit
    decision_id = bridge.submit_from_ai(
        ai_identity="GPT-4",
        context={
            "decision_id": None,  # Bridge が生成
            "scope": extract_scope_from_tags(tags),
            "note": description,
        }
    )
    
    # HAB へ approve（自動で Human Authority 経由）
    auth_id = bridge.approve_decision(
        request_id=None,  # Bridge が取得
        decision_id=decision_id
    )
    
    # JARVIS へ routing
    exec_id = bridge.route_to_jarvis(decision_id)
    
    return {
        "status": "ok",
        "decision_id": decision_id,
        "authorization_id": auth_id,
        "execution_id": exec_id,
    }
```

## 12. 創造演算エンジン（Synapse Awakening & Logic Engine）

**指示**：UNKNOWN×3（α/β/ζ）→ AND / OR / NOT → REM を、ブラウザ内で実行する。生成された横のつながり（lateral）を 3D に紫で実体化させる。

**重要な前提**：論文群（3, 3.5αβζ, 4, 5）の本文は、この環境には無い。演算子の定義は指示書の記述に基づき、判定の基準は下の「判断」として具体化した。論文の定義と異なる箇所があれば、論文と突き合わせて直す必要がある。

**判断（指示書からの具体化・変更）**
1. **α/β/ζ の定義**：α＝接続なし、または全接続が UNKNOWN のノード。β＝UNKNOWN / PENDING / PARTIAL の線（関係が未確定）。ζ＝Pending 層のノード（判断未決）。ζ でありかつ α でもあるノードは両方に入る。
2. **ホワイトスペース**：α・β・ζ のいずれかに触れる、未接続の異層ノード対。UNKNOWN×3 が無ければ AND は動かない（仕様どおり）。
3. **AND**：異層の対で、共通の「強い」接続先 C（A–C も C–B も CODE_CONFIRMED など）があること。
4. **OR**：共通接続先が複数なら、経路を全て保持する（multiPath）。
5. **NOT**：A–C または C–B が CONFIRMED_ABSENT の経路は除外し、制約として記録する。直接の絶対不在の対も制約として明示する。
6. **横のつながりは仮説**：次のラウンドでは既存の線として重複を防ぐが、根拠（強い接続）にはしない。これをしないと、仮説から仮説が連鎖して収束しなかった（実データで 92 件・3 ラウンドで打ち切りになった）。
7. **REM の追加規則**（実データで過剰生成を抑えるため）：
   - HUB_ONLY：接続数 8 を超えるハブ（例：N037 app.py、接続 11）だけで支持される対は刈る（複数経路の場合は除く）。
   - CAP_EXCEEDED：1 ラウンドの採用は 10 件まで（支持の多い順、同点は名前順で決定的に）。
   - 刈り込みの理由：SELF_LOOP / UNKNOWN_NODE / SAME_LAYER / ABSENT_PAIR / EXISTING_PAIR / BLACKLISTED_CYCLE / NO_SUPPORT / DUPLICATE / HUB_ONLY / CAP_EXCEEDED / CYCLE。

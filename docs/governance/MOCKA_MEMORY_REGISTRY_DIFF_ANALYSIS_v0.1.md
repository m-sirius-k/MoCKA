## 4.2 不一致パターン分類

- **スコープ差**: Claude.ai側はアカウントレベルのOAuth Connected App経由(2026-07-03記録・ユーザー申告に基づく間接情報)。Claude Code側はユーザースコープ(`~/.claude/settings.json`)の直接URL接続であることを本セッションで直接確認した。プロジェクトスコープ(`MoCKA/.claude/settings.local.json`)には接続定義自体が存在しない。
- **スキーマ差**: tool name prefixが人間可読名ベース(`claude_ai_MoCKA_Memory_Caliber2_01`)とUUID形式(`724b556c-...`)で異なることを設定ファイルの記録から確認した。「レジストリ」という語が複数の異なる実体(MCPツール登録機構/governance registry.json鍵台帳/Registry Series)を指しうることも確認した。
- **伝播差**: TODO_390事案(2026-06-30)でクライアント側キャッシュによる反映遅延が記録されている。2026-07-03の調査記録では同一バックエンドに対しA=tool_search失敗(0件)、B=成功(17件)という記録が残っている。
- **欠落差**: 本日のユーザー申告(claude.ai Web chatでMoCKAツールが完全に不可視、Notion関連ツールのみ表示)は、2026-07-03の記録(0件)と同種の症状として記録される。ただし本日の申告が2026-07-03と同一原因の再発か、新規の事象かは、本セッションでの再検証を行っていないため確認できていない。

上記いずれの項目も、events.db記録・本セッションで直接確認した設定ファイル・本セッションで実際に成功したツール呼び出し・ユーザー自己申告のいずれかに直接紐づく記載のみで構成した。原因の推測・解決策の提示・解釈は含めていない。「Claude.ai側」に関する記載は、くろこが直接検証したものではなく既存記録・ユーザー申告に基づく間接情報であることを、各項目で明示した。

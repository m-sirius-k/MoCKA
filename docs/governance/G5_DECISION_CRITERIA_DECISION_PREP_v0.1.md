| 追加証拠の要否 | **不要**。ただし上記の未記載事項は制度解釈の問題として残る |

### 3.7 HG-C07 Criterion 5 の対象外の扱い

| 欄 | 内容 |
|---|---|
| 論点 | 対象を構造上扱わない候補の判定値 |
| 制度的意味 | FAIL とした場合、扱わない対象の数が多い候補ほど不利になり、判定が候補の適用範囲の広さを反映してしまう。対象外とした場合、比較表に空欄相当の値が生じる |
| 制度的影響範囲 | Criterion 5 の5セル |
| 関連 Criterion | 5 |
| 関連証拠 | HG-3 は git 作業ツリーのみを扱い状態語彙を持たない (JARVIS-HGJ04-EV-001 第1章)。HG-4 は collision 裁定であり承認要求を扱わない (同 第3章)。**各候補が対象4種のどれを扱うかの網羅確認は未実施** (CH-4) |
| 未確定理由 | 扱いの決定は評価方式の制度選択。なお適用範囲の事実確認自体は比較工程の作業であり、本工程では禁止事項7に該当する |
| 追加証拠の要否 | **裁定には不要**。B (FAIL とする) を採る場合、各候補の対象適用範囲の事実確認が比較工程で必須になる |

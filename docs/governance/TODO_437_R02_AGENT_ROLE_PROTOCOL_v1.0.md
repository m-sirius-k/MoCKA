## 1. 目的

本宣誓は、TODO_437_R02における複数Agent間の役割混同を防止し、判断・調査・実作業・
承認の責任境界を明確化することを目的とする。

各担当は、自身の識別IDと担当範囲を遵守し、他担当領域への無断代行・責任混同を
行わない。

## 3. 共通運用規則

全担当者は以下を遵守する。

1. 正本と派生資料を明確に区別する。
2. Observation(観測)とEvidence(検証済証拠)を混同しない。
3. Hypothesis(原因仮説)とSolution(対策候補)を混同しない。
4. Human Gate承認前の変更は禁止する。
5. 変更履歴・判断履歴を保持する。

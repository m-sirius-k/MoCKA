## 1. 論点の前提 (Confirmed)

### 1.1 なぜ選定基準が必要か

| # | 確定事項 | 出典 |
|---|---|---|
| 1 | 検証は **サンプリング** で行う (R-4) | RULE-HGC03 |
| 2 | 検証軸の証拠要件に **サンプリング根拠 (なぜその経路を対象に選んだか)** が含まれる | v0.6 4.2.6-4 |
| 3 | **未検証の経路を安全と推定しない**。対象経路の同定が完了していない場合、当該経路について判定しない | v0.6 4.2.8 |
| 4 | **C2-b は必要条件の判定対象である** (W-7) | RULE-C2B |

1 と 2 により、**選定基準を先に確定しないと C2-b の証拠要件を満たせない**。

### 1.2 きむら博士が裁定文で示した例示 (RULE-HGC03)

> A（経路）で検証: 定義された高リスクな経路（本番アクセス、特権ID付与、本番DB変更など）において、
> 実際にHuman Gateを回避・無視できない構造になっているかを技術的に評価する。

例示は **本番アクセス / 特権ID付与 / 本番DB変更** の3つである。
**これらに対応する MoCKA 側の対象は定義されていない** (v0.6 6.2 HG-C08 の未確定内容)。

## 4. HG-C14 への依存関係整理

### 4.1 2つの裁定の役割分担 (Confirmed)

| 裁定 | 決めるもの |
|---|---|
| **HG-C08** | **どの経路を検証対象にするか** (対象集合の定義) |
| **HG-C14** | **その対象集合の判定結果から、C2-b の必要条件充足をどう判定するか** (集合上の判定規則) |

**HG-C08 が集合を決め、HG-C14 がその集合の上の規則を決める。順序は HG-C08 が先である。**

### 4.2 依存の内容 (Confirmed)

HG-C14 の選択肢 (v0.6 6.4) は次のとおり。

| # | HG-C14 の選択肢 |
|---|---|
| C14-A | サンプリングした経路がすべて PASS のときのみ充足 |
| C14-B | 1経路でも FAIL があれば不充足、それ以外は他の規則に従う |
| C14-C | 経路ごとの判定を系統単位へ集約せず、経路単位のまま Finalization へ提示する |
| C14-D | 博士が指定 |

**依存の事実:** C14-A および C14-B における「サンプリングした経路」の範囲は、**HG-C08 の裁定内容によって決まる**。
同じ C14-A でも、HG-C08 が A の場合と B の場合では判定対象の集合が異なる。

### 4.3 組合せによる意味の変化 (Confirmed / 事実の整理)

**下表は各組合せで何が起きるかの記述であり、組合せの推奨ではない。**

| HG-C08 | C14-A (全 PASS で充足) の意味 | C14-C (経路単位のまま提示) の意味 |
|---|---|---|
| A (Criterion 5 の4種) | 4種に到達する経路がすべて PASS であれば充足。**それ以外の経路は判定対象外のまま残る** | 4種に到達する経路の判定が経路単位で Finalization へ渡る |
| B (全数) | **承認到達経路の全数が PASS のときのみ充足**。範囲外の経路が存在しない | 全経路の判定が経路単位で渡る。件数は最大になる |
| C (個別指定) | 指定経路がすべて PASS であれば充足。**指定外の経路は判定対象外** | 指定経路の判定が渡る |
| D (既存保護対象) | D-1..D-4 に触れる経路がすべて PASS であれば充足。**触れない経路は対象外** | 該当経路の判定が渡る |
| E (承認確定点) | 承認確定点に到達する経路がすべて PASS であれば充足 | 該当経路の判定が渡る |

**共通する構造:** B 以外の案では、**必要条件の充足が「サンプリング範囲内での充足」を意味する**。
サンプリング範囲外の経路が Guard を持たない可能性は、C2-b の判定値には現れない。

**この構造は HG-C03 の選択肢比較資料 (`G5_HGC03_OPTION_COMPARISON_v0.1.md` 3.5) で
選択肢 B の誤りの型として記録した「見落とし」と同型である。** ただし当時は系統単位と経路単位の対比であり、
本件はサンプリング範囲の内外の対比である。**同型であることの指摘であって、いずれかの案を否定するものではない。**

### 4.4 逆依存の有無 (Confirmed)

**HG-C14 を先に確定させても HG-C08 の選択肢は制約されない。**
C14-A から C14-D はいずれも、HG-C08 のどの案とも組合せ可能である。
したがって **依存は一方向 (HG-C08 → HG-C14)** であり、
博士の指示 (HG-C14 は HG-C08 確定後に裁定) と整合する。

### 4.5 HG-C09 との関係 (Confirmed)

HG-C09 (C2-a と C2-b が食い違った場合の扱い) は継続保留であり、本資料の対象外である。
ただし事実として、**C2-b が必要条件の判定対象になった (W-7) ことにより、
C2-a と C2-b の双方が必要条件に算入される**。両者が異なる判定値を持つ場合の扱いは
S-4 により「統合値を作らずに両方を保持する」までが確定しており、その先は HG-C09 の裁定範囲である。

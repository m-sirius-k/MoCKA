## Section C. 各候補の制度的帰結

### C.1 候補 A の帰結

**判定ロジック:** サンプリング経路がすべて PASS のときのみ充足

| 帰結項目 | 内容 | 影響 |
|---|---|---|
| **充足条件** | C2-b は、サンプリング検証対象の「すべての経路」が PASS 判定を得たときのみ充足 | 極めて厳格 |
| **FAIL の扱い** | 1経路でも FAIL があれば、C2-b は不充足 | FAIL の確定性を重視 |
| **UNKNOWN の扱い** | 検証未実施（UNKNOWN）の経路がある場合、C2-b は充足しない | 保守的判定 |
| **N/A の扱い** | N/A（適用外）の経路は集約対象に含めるか除外するか（別途定義必要） | 二次的な判定ルール発生 |
| **R-4との関係** | サンプリングで得た PASS のみで充足とするため、未検証経路のリスクを「推定の安全」としない | R-4 4.2.8「未検証の経路を安全と推定しない」に整合 |
| **後続への影響** | C2-b 充足条件が最も厳格。必要条件全体の充足可能性が下がる | 承認可能候補の減少 |

### C.2 候補 B の帰結

**判定ロジック:** 1経路でも FAIL があれば不充足、それ以外は他の規則に従う

| 帰結項目 | 内容 | 影響 |
|---|---|---|
| **不充足条件** | FAIL は不充足の確定的な根拠。1経路の FAIL で C2-b は不充足 | FAIL の絶対性 |
| **PASS の扱い** | サンプリング経路に PASS があっても、他経路に FAIL があれば無効 | 部分的安全性は無視 |
| **UNKNOWN の扱い** | UNKNOWN は FAIL ではないため、「他の規則に従う」ことになるが、その規則が未定義（別途定義必要） | 二次的判定ルール発生 |
| **N/A の扱い** | N/A は判定対象外として扱う（W-7 により C2-b は判定対象に「算入」されているが、N/A 扱いは別） | 複雑な集約ロジック |
| **R-4との関係** | FAIL を確定的に不充足とするため、バイパス検証は重視する。UNKNOWN の扱いは R-4 の「サンプリング」と整合するか要確認 | R-4 との部分的整合性が検討対象 |
| **後続への影響** | FAIL がなければ PASS または UNKNOWN の混在が許容される。充足可能性は A より高い | より柔軟な判定 |

### C.3 候補 C の帰結

**判定ロジック:** 経路ごとの判定を系統単位へ集約せず、経路単位のまま Finalization へ提示する

| 帰結項目 | 内容 | 影響 |
|---|---|---|
| **集約廃止** | C2-b の系統単位 1判定値を生成しない。複数経路の判定結果を並列提示 | 系統単位の結果構造が崩壊 |
| **HG-C03 R-1 との矛盾** | HG-C03 R-1「評価粒度 = 系統単位」で確定済。C2-b も系統単位で 1判定を生成することが前提 | **直接矛盾の可能性** |
| **Finalization 手続きへの影響** | Finalization は系統単位で「全必要条件が充足されたか」を判定する（5.5.3）。経路単位の複数判定では判定不可能 | 意思決定ロジックの破壊 |
| **R-3「独立記録」との関係** | C2-a は系統単位で 1判定。C2-b が経路単位のまま提示されると、系統単位での「独立記録」が成立しない | **R-3 との矛盾の可能性** |
| **新規制度設計** | 系統単位への集約を廃止する場合、必要条件判定全体を再設計する必要がある | **大規模な制度変更** |
| **後続への影響** | HG-C03 の確定事項を修正することになり、Human Authority の追加判断が必須 | **HG-C03 の再裁定が必要** |

### C.4 候補 D の帰結

**判定ロジック:** 博士が指定

| 帰結項目 | 内容 | 影響 |
|---|---|---|
| **内容不確定** | 候補 A/B/C の外、または複合条件を Human Authority が明示判定する | あらゆる可能性が開放 |
| **例示** | 例：「HG-C08 の裁定結果に応じて A か B を選択」「経路グループごとに異なるルール適用」「時間軸に応じた段階的ルール」など（推論例のため非拘束） | 複数の実装パターン可能 |
| **後続への影響** | 博士の判定後に初めて実装方針が確定 | 実装スケジュール未定 |

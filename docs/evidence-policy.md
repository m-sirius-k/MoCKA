# 証拠の原則（Evidence Policy）

1. **実データの線は、実データの証拠でしか緑にしない。** 赤い線（CONFIRMED_ABSENT / UNKNOWN）は、3条件（存在・ID連鎖・承認の正当性）がすべて `real` の観測で PASS するまで赤のまま。
2. **シミュレーター由来の記録は「模擬（simulation）」として隔離する。** 架空の承認・認可・実行の記録は、どの条件も通さない。実データの線の状態を書き換える根拠には使わない。
3. **オーバーレイは証拠ではない。** 3D 上の表示用の経路線（Synapse オーバーレイ）と、紫の横のつながり（仮説）は、実データの線として扱わない。
4. **判定は書き換えない。** 証拠チェッカーは `GREEN_CANDIDATE` / `RED_UNCHANGED` を返すだけ。データは変更しない。`GREEN_CANDIDATE` でも自動反映はせず、人の確認を経た別の手続きで扱う。
5. **不足は不足のまま見せる。** 証拠が無いものは UNKNOWN として表示する。P3（構造外）の絶対不在も隠さず、「構造外」と分類して残す。

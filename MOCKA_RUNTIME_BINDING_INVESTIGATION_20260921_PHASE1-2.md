## KEY FINDINGS (PHASE 1-2)

### FINDING 1: Request-Level ID Exists
- **Status:** VERIFIED
- **Location:** JSON-RPC "id" field, extracted at line 1271
- **Usage:** Idempotency check (request_executions table)
- **Propagation:** Passed to execute_tool() → stored in table → used for dedup

### FINDING 2: Governance Gate Before Execution
- **Status:** VERIFIED
- **Location:** governance_pipeline.py:before_tool() line 114
- **Authority validation:** BA-04 authority decision reading from Decision Ledger
- **Decision reading:** governance_pipeline.py:_read_decision() line 91-112
- **Blocking mechanism:** BLOCK event recorded if decision.allowed == False

### FINDING 3: Decision ↔ Request Linkage Missing
- **Status:** NOT VERIFIED
- **Issue:** req_id passed to before_tool() but NOT linked to decision_id
- **Evidence:** governance_pipeline.py:before_tool() line 138 reads decision_id from args, but req_id not stored in decision record
- **Consequence:** Tracing from decision → specific execution is possible (via decision_id lookup), but tracing from req_id → executed decision requires manual correlation

### FINDING 4: Event ↔ Request Linkage Partial
- **Status:** PARTIAL
- **Evidence:** mocka_mcp_server.py:mocka_write_event() line 836: `"request_id": req_id` included in gate_payload
- **Question:** Does GATE actually store request_id in events table? (NOT YET VERIFIED)
- **Status of fallback:** offline fallback (line 865) also passes gate_payload with request_id

### FINDING 5: Execution Outcome ID Missing
- **Status:** NOT FOUND
- **Gap:** Once tool execution completes, there is no unique identifier linking:
  - The specific request (req_id)
  - To the specific execution (MISSING)
  - To the specific result (event_id or decision_id)
- **Current state:** req_id→auto_log(tool_name) exists, but no req_id→(event_id | decision_id) binding

### FINDING 6: Governance Block Recording Exists
- **Status:** VERIFIED
- **Location:** mocka_mcp_server.py:_record_governance_block() line 283
- **Mechanism:** Creates event via GATE when before_tool() returns allowed==False
- **Record fields:** req_id, tool_name, decision_reason, decision_id
- **Storage:** Gate event (events.db), not linked back to decision_ledger
